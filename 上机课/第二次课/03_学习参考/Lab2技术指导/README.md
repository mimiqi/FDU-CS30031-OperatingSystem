# Lab2 技术指导与参考代码

本学习包是第二次上机课准备阶段的参考材料，包含 Trace、RISC-V 问答、Backtrace 和 Alarm 的指导与参考代码；原交付范围按当时要求跳过 Attack，不包含 Attack 实现。

后续实际实验已经在 VMware Ubuntu 中完成，完整评分为 **System calls 50/50、Traps 95/95**，真实记录见 [02_实验报告](D:/Text/21_操作系统/上机课/第二次课/02_实验报告)。这不等于本目录内每份独立参考快照都重新执行过测试，最终提交以虚拟机中的实际代码为准。

本包用于阅读、对照和复习。文中的安装、编译、QEMU 和测试命令只供 **VMware 中的 Ubuntu 24** 使用；不在 Windows 或 WSL 中实施实验。参考材料中的“未运行”及预期输出描述的是原材料交付边界，不是当前实际实验的完成状态。

## 参考代码如何组合

`syscall` 和 `traps` 是两条不同的实验分支，不应把它们的修改混在同一个分支里。

- `syscall`：本包只提供 Trace 补丁，没有 Attack 实现；不能用它替代已经通过完整评分的实际 System calls 代码。
- `traps`：先使用 Backtrace 补丁，再使用 Alarm 补丁；或者在干净基线上只使用一次 `参考补丁/traps-all.patch`。
- RISC-V 问答不需要修改内核。第 3、4 题的具体地址依赖最终生成的 `user/call.asm`，提供查找方法和填写位置，不虚构固定地址。

逐模块补丁与合并补丁是两种替代方式，不能重复应用。完整文件用于对照，不建议整目录覆盖已有代码。
